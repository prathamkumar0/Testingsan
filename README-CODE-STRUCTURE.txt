SANPREET MAKEUPSTORIES - CLEAN WEBSITE CODE

Structure:
- index.html and other .html files = individual pages
- styles.css = all shared design, responsive CSS and animations
- script.js = menu, page transitions, scroll reveal, gallery/lightbox, page-cut manager and interactions
- assets/ = all website images

All pages use the same styles.css and script.js so design and animations stay consistent.
The code has been formatted into readable multi-line HTML/CSS/JS files for editing in VS Code.
